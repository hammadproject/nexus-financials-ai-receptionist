# Nexus Financials — Vapi Voice Receptionist

Vapi has been connected to the static website using the official Vapi web widget.

- Public API Key: configured in the HTML widget
- Assistant ID: Bright Smile Dental Receptionist (configured as provided)
- Mode: Voice

## Run

This is a static website. You can open `index.html` directly, but microphone/browser security works more reliably from a local web server.

For example with VS Code Live Server, open `index.html` and click the Vapi voice button.

## Important

The Vapi public key is intended for client-side integrations. Do not put a Vapi private key in the website.

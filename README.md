# Nexus Financials


<img width="1519" height="765" alt="image" src="https://github.com/user-attachments/assets/79c4d4d4-0313-4066-8868-487b6e04e016" />


Nexus Financials is a modern, responsive financial services website designed to provide visitors with a clear and professional way to explore financial services, learn about the business, and get in touch with the team.

The website also includes an integrated AI voice receptionist powered by Vapi, allowing visitors to interact with an AI assistant directly from the website.

## Overview

Nexus Financials is built with a clean, modern visual style focused on usability, accessibility, responsiveness, and professional presentation.

The website is designed to work across:

- Desktop computers
- Laptops
- Tablets
- Mobile devices

The project uses a lightweight front-end architecture based on HTML, CSS, and JavaScript, making it easy to deploy and maintain.

---

## Features

### Responsive Design

The website is fully responsive and adapts its layout to different screen sizes.

It supports:

- Desktop layouts
- Tablet layouts
- Mobile layouts
- Responsive navigation
- Responsive forms
- Mobile-friendly AI receptionist interface

---

### AI Voice Receptionist

Nexus Financials includes an AI-powered voice receptionist integrated with Vapi.

The AI receptionist can:

- Greet website visitors
- Answer incoming conversations
- Collect basic information
- Collect caller names
- Collect callback numbers
- Collect enquiry details
- Confirm important information
- Provide a professional first point of contact
- Handle general enquiries

The receptionist is designed to provide a warm and professional experience while avoiding unsupported financial or professional advice.

## AI Receptionist

The website uses a Vapi-powered voice assistant.

### Assistant

**Nexus AI Receptionist**

The assistant is configured to provide a professional and welcoming experience for Nexus Financials visitors.

Example greeting:

> "Thank you for contacting Nexus Financials. This is our virtual receptionist. How may I help you today?"

The assistant can be accessed directly through the website's voice interface.

## Contact Form

The website includes a contact/enquiry form that allows visitors to submit their information.

The form includes fields such as:

- Name
- Company
- Email
- Phone
- Service
- Message
- Enquiry confirmation

The form is designed to make it easy for potential clients to provide their requirements and request further information.
